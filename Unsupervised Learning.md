Unsupervised learning involves no labeled examples for training of the model.

There are 3 major types of unsupervised learning
1. Clustering
2. Anomaly Detection — see [[Anomaly Detection Algorithms]]
3. Density Estimations — for example [[Gaussian Mixture Models]]

**Clustering**

Application of Clustering
1. Customer Segmentation
2. Data Analysis
3. Dimensionality Reduction
4. Anomaly Detection
5. Semi-Supervised Learning
6. Search Engines
7. Image Segmentation

## Algorithms

- [[K Means|KMeans]] — Centroid-based clustering into $k$ groups.
- [[Heirarchical Clustering|Hierarchical Clustering]] — Nested clusters and dendrograms.
- [[DBSCAN]] — Density-based clusters with a noise label.
- [[Gaussian Mixture Models]] — Probabilistic soft clustering and density estimation.
