## Overview

A Gaussian mixture model (GMM) assumes the data were generated by a mixture of a finite number of Gaussian (normal) distributions with unknown parameters.[^sk-guide] Each Gaussian is a **component**; fitting the model finds each component's weight, mean, and covariance.

As a clustering method, a GMM gives **soft assignments**: the probability that each point belongs to each component. It can be viewed as a generalisation of [[K Means]] that also learns the covariance (shape and orientation) of each cluster.[^sk-guide] Because it is a full probability model, it can also be used for density estimation, sampling new points, and scoring how unusual a point is.

## Key Concepts

For $K$ components in $d$ dimensions, the density of a point $x$ is

$$
p(x) = \sum_{k=1}^{K} \pi_k\, \mathcal{N}(x \mid \mu_k, \Sigma_k).
$$

- $\pi_k$: the **mixing weight** of component $k$, with $\pi_k \ge 0$ and $\sum_k \pi_k = 1$.
- $\mu_k$: the component mean, a cluster centre.
- $\Sigma_k$: the component covariance, which sets the cluster's spread, shape, and orientation.
- $\mathcal{N}(x \mid \mu, \Sigma)$: the multivariate normal density; see [[Probability Density Function]].

The **responsibility** $\gamma_{ik}$ is the probability that component $k$ generated point $x_i$:

$$
\gamma_{ik} = \frac{\pi_k\, \mathcal{N}(x_i \mid \mu_k, \Sigma_k)}{\sum_{j=1}^{K} \pi_j\, \mathcal{N}(x_i \mid \mu_j, \Sigma_j)}.
$$

A hard cluster label, if needed, is the component with the largest responsibility.

## Fitting with Expectation–Maximisation

scikit-learn fits `GaussianMixture` with the expectation–maximisation (EM) algorithm.[^sk-guide]

1. **Initialise** the weights, means, and covariances. scikit-learn's default initialises the responsibilities with k-means.[^sk-api]
2. **E-step:** compute each point's responsibilities under the current parameters.
3. **M-step:** re-estimate the parameters from the responsibility-weighted points. With $N_k = \sum_i \gamma_{ik}$:

$$
\pi_k = \frac{N_k}{N}, \qquad \mu_k = \frac{1}{N_k}\sum_{i=1}^{N} \gamma_{ik}\, x_i
$$

$$
\Sigma_k = \frac{1}{N_k}\sum_{i=1}^{N} \gamma_{ik}\,(x_i - \mu_k)(x_i - \mu_k)^\top
$$

4. **Repeat** until the improvement in the log-likelihood falls below a tolerance.

Like k-means, EM can converge to a local optimum, so running several initialisations (`n_init`) and keeping the best fit is common. With hard 0/1 responsibilities and equal spherical covariances, the M-step for the means reduces to the k-means centroid update. scikit-learn describes k-means as equivalent to EM with a small, all-equal, diagonal covariance.[^sk-kmeans]

### Covariance types

`covariance_type` trades flexibility against the number of parameters:[^sk-api]

| Type | Each component has | Cluster shape |
|---|---|---|
| `full` (default) | Its own general covariance matrix | Any ellipse, any orientation |
| `tied` | One covariance matrix shared by all | Same ellipse everywhere |
| `diag` | Its own diagonal covariance | Axis-aligned ellipses |
| `spherical` | Its own single variance | Circles of different sizes |

## Worked Example: Soft Assignment in One Dimension

**Inputs:** two components with equal weights $\pi_1 = \pi_2 = 0.5$, means $\mu_1 = 0$ and $\mu_2 = 4$, and the same standard deviation $\sigma = 1$. With equal weights and variances, the shared factors cancel, so

$$
\gamma_{i1} = \frac{e^{-(x_i - 0)^2/2}}{e^{-(x_i - 0)^2/2} + e^{-(x_i - 4)^2/2}}.
$$

**Step 1: point $x = 1.5$.**

$$
\gamma_{1} = \frac{e^{-1.125}}{e^{-1.125} + e^{-3.125}} = \frac{1}{1 + e^{-2}} \approx 0.881
$$

**Step 2: point $x = 2$, exactly halfway.**

$$
\gamma_{1} = \frac{e^{-2}}{e^{-2} + e^{-2}} = 0.5
$$

**Step 3: point $x = 3$.**

$$
\gamma_{1} = \frac{e^{-4.5}}{e^{-4.5} + e^{-0.5}} = \frac{1}{1 + e^{4}} \approx 0.018
$$

**Step 4: point $x = 2$ with unequal weights, $\pi_1 = 0.2$ and $\pi_2 = 0.8$.**

$$
\gamma_{1} = \frac{0.2\, e^{-2}}{0.2\, e^{-2} + 0.8\, e^{-2}} = 0.2
$$

k-means would give $x = 1.5$ and $x = 3$ a hard label with no indication of doubt. The GMM reports 88% versus 2% membership in component 1, and exactly 50% at the midpoint. Step 4 shows that the mixing weights shift ambiguous points towards the larger component. These values were recalculated in Python.

## Choosing the Number of Components

Fit models with different $K$ (and covariance types) and compare the Bayesian Information Criterion; lower BIC is better.[^sk-api] BIC penalises extra parameters, so a `full` model with many components must improve the likelihood enough to justify its size. Log-likelihood alone always improves as $K$ grows and cannot be used on its own.

The variational `BayesianGaussianMixture` offers another route: given an upper bound on the number of components, a concentration prior drives the weights of unneeded components towards zero.[^sk-guide]

## Python Example

Executed with scikit-learn 1.9.1.

```python
import numpy as np
from sklearn.mixture import GaussianMixture

rng = np.random.default_rng(0)
X = np.vstack([
    rng.normal([0, 0], [1.0, 0.3], size=(200, 2)),  # elongated cluster
    rng.normal([4, 2], [0.5, 0.5], size=(100, 2)),
])

for k in (1, 2, 3, 4):
    gmm = GaussianMixture(n_components=k, covariance_type="full", n_init=5, random_state=0).fit(X)
    print(k, round(gmm.bic(X), 1))

best = GaussianMixture(n_components=2, n_init=5, random_state=0).fit(X)
print(best.weights_)
print(best.predict_proba(X[:3]))  # soft memberships
print(best.score_samples(X[:3]))  # log-density; low values suggest outliers
```

BIC was 1796.4, 1379.9, 1411.1, and 1439.0 for $K = 1$ to 4, so BIC correctly chose the two components used to generate the data. The fitted weights were 0.667 and 0.333, matching the 200/100 split. The first three points, all from the elongated cluster, had membership probabilities of about 1 for one component.

## Limitations & Common Pitfalls

- **Gaussian shapes only.** A mixture of ellipses cannot represent crescents or rings with few components; see [[DBSCAN]] for arbitrary shapes.
- **Singular covariances.** A component can collapse onto a few nearly identical points, driving its variance towards zero and the likelihood towards infinity. scikit-learn adds `reg_covar` to the covariance diagonal to keep it positive.[^sk-api] The variational method avoids many of these singularities at the cost of some bias.[^sk-guide]
- **Parameter count.** A `full` covariance has $d(d+1)/2$ free values per component; in high dimensions consider `diag`, `tied`, or dimensionality reduction first.
- **Local optima and initialisation.** Use several initialisations and check `converged_`.[^sk-api]
- **Probabilities are model-based.** Responsibilities are only as trustworthy as the Gaussian assumption; they are not calibrated class probabilities. See [[Probability Calibration]].

## Exercise

A GMM with $K = 3$ has a lower log-likelihood on the training data than one with $K = 6$, but a lower BIC. Which would you choose, and why might the $K = 6$ model still be preferred?

> [!example]- Exercise solution
> Prefer $K = 3$ by default: the $K = 6$ model's likelihood gain does not justify its extra parameters, which suggests it is fitting noise. It may still be preferred if the downstream use needs finer segments and they are stable and interpretable, for example if the extra components match distinct, actionable customer groups in held-out data. BIC is a guide, not the objective.
